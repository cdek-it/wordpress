# Настройка

## Блок "Авторизация"

Доступ к настройкам можно получить по ссылке на странице со списком плагинов.

<Image img={require('./img/setup.png')} />

Прежде всего необходимо заполнить поля **Идентификатор**, **Секретный ключ** и **Ключ Яндекс.Карт**, после чего нажать кнопку
**Сохранить изменения**. Только после сохранения настроек можно переходить к заполнению остальных полей.

<Image img={require('./img/settings.png')} />

Далее переходим к **настройкам плагина**.

Напротив некоторых полей расположен значок вопроса. При наведении на него отобразится подробная информация о соответствующем поле.

## Блок "Клиент"

На вкладке **Клиент** необходимо заполнить данные, которые будут использоваться в качестве данных отправителя.
Необходимо **обязательно** ввести адрес для отправки груза (заказов) - для тарифов от склада\двери.

<Image img={require('./img/setting-client.png')} />

## Блок "Международные заказы"

При необходимости оформления международных отправлений необходимо заполнить все поля на вкладке
**Международные заказы**, а также активировать соответствующий чекбокс.

<Image img={require('./img/setting-internalorder.png')} />

## Вкладка "Автоматизация"

Вкладка **Автоматизация** позволяет выбрать условия, при которых накладная СДЭК будет создаваться автоматически
после оформления заказа клиентом.

При выборе настройки **«Ожидать платежные шлюзы»** плагин будет ожидать завершения обработки платежа выбранными
платежными шлюзами перед автоматическим созданием накладной СДЭК. Если заказ использует платежный шлюз,
который не был выбран, накладная СДЭК будет создана сразу после оформления заказа.

<Image img={require('./img/setting-auto.png')} />

## Вкладка "Доставка"

На вкладке **Доставка** необходимо выбрать тарифы. Для выбора нескольких тарифов удерживайте клавишу **Ctrl**.

<Image img={require('./img/setting-delivery.png')} />

При необходимости можно включить режим **многоместных отправлений**. В этом случае заказ необходимо создавать
из административной панели и указывать количество мест в заказе.

**Доп. дни к доставке** — количество дней, которое будет добавлено к расчетному сроку доставки на странице
оформления заказа. (Например, если Вы собираетесь передать заказ не сегодня, а на следующий день).Если Вы хотите,
чтобы после выбора ПВЗ покупателем карта автоматически закрывалась - активируйте чекбокс **Закрыть карту после выбора ПВЗ**.

Необходимо обязательно указать адрес отправления грузов (заказов) для тарифов **от склада** и **от двери**.
<Image img={require('./img/address.png')} />

:::warning

**Обратите внимание:** город необходимо выбрать из выпадающего списка. Он станет доступен после заполнения
ключей СДЭК и Яндекс.Карт и сохранения настроек.

:::

## Блок "Габариты"

По умолчанию габариты берутся из карточки товара.

В данных полях можно указать габариты среднего товара. Эти значения будут использоваться при
определении габаритов к расчету в корзине.

При необходимости можно включить чекбокс **«Габариты товара вкл/выкл»**. В этом случае при расчете стоимости
доставки будут принудительно использоваться габариты, указанные в настройках плагина, а значения из карточки товара будут игнорироваться.

В поле **«Коэфициент на упаковку»** вы можете добавить запас на пустоту внутри коробки.
Это нужно, чтобы учесть пустое пространство внутри упаковки.

По умолчанию установлено значение **1**. Допустимый диапазон: от **1** до **1.15** (включительно).

Значение 1.1 добавит к высоте 10% запаса, 1.15 — 15%.

<Image img={require('./img/setting-dimensions.png')} />

## Блок "Услуги"

В блоке **«Услуги»** можно подключить дополнительные услуги, которые будут автоматически применяться
к создаваемым заказам.

<Image img={require('./img/setting-services.png')} />

## Блок "Стоимость доставки"

В блоке **«Стоимость доставки»** можно:
- установить наценку или скидку на стоимость доставки
- добавить к расчету стоимость страховки. Размер страховки рассчитывается как **0,75%** от стоимости товаров в заказе

<Image img={require('./img/setting-pricedelivery.png')} />
